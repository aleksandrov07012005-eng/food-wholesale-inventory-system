# Информационная система прогнозирования потребности и управления запасами для предприятия оптовой торговли продуктами питания
Данный проект представляет собой автономное веб-приложение для предприятий оптовой торговли продуктами питания. Система автоматизирует партионный учет складских запасов и использует алгоритмы машинного обучения для прогнозирования спроса, что позволяет минимизировать списания просроченной продукции и предотвращать дефицит товаров.

## Основные возможности
* Партионный учет и адресное хранение товаров.
* Контроль сроков годности и автоматическая блокировка отгрузки просроченной продукции.
* Предиктивная аналитика на базе машинного обучения для формирования планов закупок.
* Ролевая модель доступа для руководства, коммерческого отдела и складского персонала.
* Автономная работа в локальной сети предприятия.
