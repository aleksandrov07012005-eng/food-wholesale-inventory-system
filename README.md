# Информационная система прогнозирования потребности и управления запасами для предприятия оптовой торговли продуктами питания
Автономное веб-приложение для предприятий оптовой торговли продуктами питания. Система объединяет строгий партионный учет складских запасов и алгоритмы машинного обучения для предиктивного планирования закупок, что позволяет минимизировать списания просроченной продукции и предотвращать дефицит товаров.

## Основные возможности
***Партионный учет и адресное хранение:** фиксация каждой партии товара с указанием даты производства, срока годности и конкретной складской ячейки.
***Контроль сроков годности:** автоматическая блокировка отгрузки просроченной продукции. При комплектации заказов приоритет отдается товарам с наименьшим остаточным сроком годности.
***Предиктивная аналитика:** модуль машинного обучения анализирует историю продаж и сезонность для автоматического формирования рекомендуемых планов закупок.
***Ролевая модуль доступа:** разграничение прав доступа для трех категорий пользователей: руководство, коммерческий отдел и складской персонал.
***Автономность:** развертывание на локальных серверах предприятия без зависимости от сторонних облачных сервисов.
