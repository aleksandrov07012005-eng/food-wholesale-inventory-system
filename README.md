# Информационная система прогнозирования потребности и управления запасами для предприятия оптовой торговли продуктами питания
Автономное веб-приложение для предприятий оптовой торговли продуктами питания. Система объединяет строгий партионный учет складских запасов и алгоритмы машинного обучения для предиктивного планирования закупок, что позволяет минимизировать списания просроченной продукции и предотвращать дефицит товаров.
